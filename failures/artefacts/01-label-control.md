# 01. The label control killed seven variables at once

**Where:** the first environmental variable search

## What was claimed

Seven environmental variables predict the gravitational residual.

|  |  |
|---|---|
| the number that looked real | **1.1% gain on the real data** |
| the same number under control | **6.1% gain on data containing only survey structure and no physics** |

## Why it happened

The search space was rich enough that the selection procedure could fit survey geometry. Running it on structure-only data did not merely reproduce the result -- it scored HIGHER, because the structure-only data had no physics competing with the geometry.

## What caught it

Run the identical search on data that cannot contain the answer.

## The lesson

A null that beats the data is not a weak result, it is a diagnosis. The method was measuring the survey.

**Cost of the control:** One extra run of a search that had already been written.
