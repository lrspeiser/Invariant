# Invariant

Invariant is a creativity-first system for generating and recombining mathematical and scientific
ideas, with independent falsification and formal testing controlling what may be claimed—not which
ideas remain explorable. The Python distribution and import
namespace retain the historical `sigma-theory-compiler` / `sigma_theory_compiler` names for
artifact and API compatibility.

This repository is the canonical home of the former
`research/sigma-theory-compiler` project. Its filtered history, immutable evidence, generator
outputs, and Git LFS data were migrated from `lrspeiser/sigmagravity`; see
[`docs/provenance/INVARIANT_MIGRATION.md`](docs/provenance/INVARIANT_MIGRATION.md).

Current development is organized around a breadth-first
[`comprehensive alpha`](docs/COMPREHENSIVE_ALPHA.md): one replayable vertical slice for every major
generator, verifier, scheduler, accelerator, and observational adapter before deeper domain
exhaustion resumes. The milestone distinguishes implementation, end-to-end exercise, and scientific
validation so systems progress cannot be mistaken for a theorem or empirical claim.

The current requirement-by-requirement status, receipt-backed measurements, unresolved blockers,
and release priorities are maintained in
[`docs/GOALS_AND_MEASURED_OUTCOMES.md`](docs/GOALS_AND_MEASURED_OUTCOMES.md).

The supported shareable distribution is a versioned standalone source-release ZIP containing a
normal non-editable wheel, the complete tracked resource surface, and hydrated hash-bound Git LFS
evidence. Build, install, verification, public PASS/REJECT examples, and isolated acceptance are
documented in [`docs/STANDALONE_DISTRIBUTION.md`](docs/STANDALONE_DISTRIBUTION.md).

## The compiled theory class

The parent static functional is

```text
I_stat = integral d^3x { [H(D,nabla D,Z_b) - D dot nabla W]/(4 pi G) - rho_b W }
```

with

```text
H = D^2/2 + epsilon a_sigma^2 f(x,q,z)
x = D^2/a_sigma^2
q = L_sigma^2 (partial D)^2/a_sigma^2
z = Z_b^2/Z_0^2
```

The included MVP grammar uses atoms `x`, `q`, and `z`; unary operators `sqrt(1+u)-1` and `u/(1+u)`; commutative `+` and `*`; both signs of a frozen coupling magnitude; and a maximum expression-tree complexity of four. “Exhaustive” means every syntax tree in exactly that finite language, followed by canonical algebraic deduplication.

## Gate contract

Implemented kill gates:

- normalized-invariant dimensional consistency;
- finite and zero correction at the vacuum origin;
- high-field Newtonian decoupling on the declared ray;
- dependence on new spatial-state information (`q` or `z`), excluding flux-only AQUAL rediscovery;
- five-universal-constant cap;
- first-derivative static action / second-order static equation;
- one constitutive law with no object switch or lensing-only coefficient;
- sampled positive-definiteness of the radial `(D, partial_r D)` constitutive Hessian.

The convexity sampler is a falsifier: one bad point kills a candidate, while a pass is not a proof of global tensor convexity.

Always deferred in this MVP:

- construction of a diffeomorphism-invariant covariant action;
- complete constraint algebra, degree count, and bounded physical Hamiltonian;
- characteristic cones and well-posedness on flat, FLRW, tilted, and curved backgrounds;
- derivation of one matter/lensing metric;
- explicit Cassini and Mercury limits;
- SPARC, cluster radial, raw-lensing, and sealed-holdout tests.

This prevents the most dangerous category error in automated theory search: confusing a good static formula with a viable theory.
