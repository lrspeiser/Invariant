# Local gas supplies a conditional calibration contribution

The adopted plane-parallel gas profiles give Gaussian-averaged mass densities of **0.01604 and 0.009157 Msun/pc^3**, for averaging lengths250 and500pc. In our response prescription these correspond to gas-only epsilon values **0.6928 and0.5824**. Analytic convolution agrees with separate quadrature to3.33e-16 relative error; all declared limiting checks pass.

These are calculations from a published model, not measurements of the complete local coefficient. Under the adopted profiles, adding nonnegative stellar matter can only increase epsilon. That conditional ordering does not make the numbers observational lower confidence bounds: conversion errors, nearby structure and the Sun's position are not propagated.

The numeric source is [McKee, Parravano & Hollenbach2015](https://arxiv.org/html/1509.05334v1), Table2. Hydrogen-nuclei profiles include molecular, cold/warm atomic and ionized gas; a1.4 mass factor includes helium. The smooth ionized profile excludes the Gum Nebula. Column discrepancies of0.26–4.29% are retained for the neutral components; the ionized5.56% difference also includes that missing component. No profile was renormalized to conceal those differences.

We did not adopt the paper's full stellar model as an independent calibration. SectionIV.1 describes relative stellar scale heights inherited from Poisson-Boltzmann modeling. Such dependence must be carried explicitly when testing another gravity law. Star counts and gas observations remain useful, but a compiled mass model is not automatically independent of gravity assumptions.

Our calculation assumes translation invariance in the plane and evaluation at the midplane. It excludes stars, remnants, local spatial features and any dark-matter component. The point is to start a source-side calibration with explicit missing pieces. No laboratory, Solar-System or galaxy velocity observation was fitted. Applying these values as the actual laboratory normalization is not admitted.

Source HTML bytes and their hash are retained privately; the public receipt binds the exact version, script and preflight. Density conversion approximates hydrogen mass by proton mass (electron correction below0.06%). This is much smaller than the unmodeled source uncertainties and is not a claimed precision of the inferred local environment.
