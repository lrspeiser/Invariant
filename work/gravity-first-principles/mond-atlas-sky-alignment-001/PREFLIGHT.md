# Fixed sky-direction experiment

Freeze configuration before examining sky/residual relationships. The metadata
join counted 86 directly traceable PROBES matches; no correlations were computed.
Use Planck 2013 Table 18 SMICA KQ-corrected axes: Galactic (224.2,69.2) quadrupole
and (239.0,64.3) octopole. Their normalized bisector is a derived sensitivity
direction, not a third independent physical axis. Both signs represent the same
axis. P2(dot) tests axial alignment; signed dot separately tests hemispheres.

Compare Galactic latitude, ecliptic latitude and equatorial declination as
observational-direction controls. No free-axis or angular-threshold search.
Use the unchanged published radial residual target, not failed 3D calculations.
Controls include acceleration, quality, inclination, stellar/gas summaries,
distance and catalog foreground-extinction estimate. These are partial controls,
not assurance of removing observational bias.

Before opening response values for this run, verify spherical geometry,
antipodal symmetry, independent coordinate rotation, residualization against
independent least squares, planted directional recovery and outer-label isolation.
Run all prespecified associations, max-statistic residual shuffles, ordinary
whole-galaxy nested ridge prediction and an additional Galactic-octant holdout.
Report every outcome, feature confounding, missing rows and octant counts.
Preserve fixed-axis and in-sample associations separately from prediction scores.
No dark-matter estimates or axis-fitted gravity parameters enter the predictors.
