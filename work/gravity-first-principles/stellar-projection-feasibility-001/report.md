# Simple centrally concentrated source models fail several projected profiles

Tested nonnegative sums of Plummer spheres against every recovered projected-mass bracket, using three preset scale grids. Only ZW1215 is feasible within all original brackets. No gravity or pressure residual entered the source optimization.

| Cluster | Minimum additional fractional mass allowance, 128 scales |
| --- | ---: |
| A1795 | 19.79% |
| A2142 | 12.05% |
| A2319 | 45.68% |
| A85 | 8.12% |
| ZW1215 | 0% |

The allowance is added outside the original lower/upper brackets as a fraction of each measured mass. It is not a measurement error estimate or significance. All solutions were checked directly against their constraints. Doubling the scale count or extending its outer range does not change which clusters are feasible.

A separate necessary-condition check explains part of the failure. If projected surface density decreases with radius, average surface density Mprojected(<R)/(pi*R²) cannot increase. Even the outer lower mass bound exceeds the corresponding inner upper bound in this average-density test by factors 1.35, 1.14 and 2.64 for A1795, A2142 and A2319 respectively. Thus no decreasing projected-density curve can stay inside every quoted bracket for these objects. A85 does not violate this particular necessary condition; its Plummer-mixture failure has a narrower interpretation.

This does not reject spherical positive sources generally, much less any gravity theory. Shell-like structure, centering, source substructure, correlated uncertainties and geometry assumptions remain relevant. Nor does ZW1215's feasible mixture establish a unique or physically correct deprojection.

Next source tests must include positive radial shell distributions or another representation allowing nonmonotonic density, then assess conditioning and physical source uncertainties. A source that requires a different representation must not be silently removed from the population. The inherited full-force derivative requirements still apply.
