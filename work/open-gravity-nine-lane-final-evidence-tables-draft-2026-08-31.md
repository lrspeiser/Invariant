## 1. Auditable ranking rule and five independent judgments

The rank is a **next-test workflow priority**, not a probability that a theory is true and not a sum of the five judgments. It is determined by the first matching decision state below; each state has one lane in the current evidence snapshot, so no subjective tie-break was needed.

| Priority state | Exact rule |
|---|---|
| R0 | A real-response diagnostic exists and a stronger coherent registered test is at a frozen pre-response power/optimizer gate. |
| R1 | Exact public development sources, immutable split and audited executor exist, but a registered null/permutation contract failed before the first score. |
| R2 | Exact target source bytes are acquired for a joint response test, but source bindings or method audit block scientific decoding/scoring. |
| R3 | Multiple same-grid mechanisms make frozen real-source predictions, but no independent scientific response has been opened. |
| R4 | Law and response-blind predictions exist, but every registered object lacks the minimum scoreable response product. |
| R5 | Programs are executable/typed, but every empirical manifest remains source-blocked. |
| R6 | Receiver dynamics and a real-data likelihood are frozen, but the required matched source data are unavailable. |
| R7 | The registered experiment failed planted-signal recovery before real response access. |
| R8 | A registered held-out real-response test completed and failed its frozen observation gate; unopened controls remain sealed. |

Judgment vocabulary is deliberately non-composite:

- **Empirical fit:** `ZERO_SCORE`, `SOURCE_ONLY`, `REAL_DIAGNOSTIC_NO_SUPPORT`, `REAL_REGISTERED_FAIL`, or `ROBUST_HELDOUT_SUPPORT`.
- **Structural identifiability:** whether the present pipeline can distinguish the mechanism from declared alternatives; this does not judge truth.
- **Physical consistency:** conservation/covariance/causality/health only; it never overwrites an empirical result.
- **Novelty:** `KNOWN/NEIGHBOR`, `POSSIBLY_DISTINCT_UNVERIFIED`, or `ESTABLISHED`; no lane currently reaches established novelty.
- **Publication value:** what can honestly be published now; no lane currently supports a positive new-gravity claim.
