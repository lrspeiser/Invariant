==============================================================================
5.  THE SHARED-DENOMINATOR NULL
==============================================================================
   |Phi_b| and g_bar are both G-times-the-same-M_b, and nu_obs has
   g_bar in its denominator.  A global rescale M_b -> (1+delta) M_b
   moves log g_bar and log|Phi_b| by +delta and log nu_obs by -delta:
   the error vector lies EXACTLY along the (g_bar, Phi_b) degeneracy,
   so it is removed by controlling for log g_bar -- to first order.
   It is NOT removed for radius errors, for radius-dependent mass
   errors, or for errors in the outermost point, which move the Phi
   tail without moving g_bar at inner radii.  So the null is simulated.

   OBSERVED beta (log nu ~ quad(log g_bar) + beta log|Phi_b|):
      no other control          beta = +0.1716   -> q = 2 beta = +0.3431
      + class dummies           beta = +0.0914
      + log r                   beta = +0.0935   (log r and log|Phi| are near-duplicates: expect instability)

   LABEL CONTROL (the bench's mandatory `confound` test).  Replace
   log|Phi_b| by a bare class index 1..6 and refit:
      log|Phi_b|               R2 = 0.8748   partial corr with the g_bar-residual = +0.5270
      bare class index 1..6    R2 = 0.8663   partial corr with the g_bar-residual = +0.4778
      log r                    R2 = 0.8744   partial corr with the g_bar-residual = +0.5249
      If the bare label matches log|Phi_b|, the variable under test
      is the dataset, not the physics.

   H0 truth: log10 nu = quadratic(log10 g_bar) with per-system
   intrinsic scatter 0.250 dex drawn INDEPENDENTLY of |Phi_b|.
   Then the observed quantities are generated with the actual error
   covariance: a coherent per-system M_b error moves log g_bar and
   log|Phi_b| by +delta and log nu by -delta; a distance error moves
   log g_bar by -2eps, log|Phi_b| by -eps and log nu by 0 (both g's
   scale as 1/r^2 for the X-ray rungs and as 1/r for the rotation
   curves, and the ratio is what enters).

   Null under H0, 2000 draws (per-system M_b 0.10-0.30 dex, per-point 0.05-0.15 dex,
    distance 0.05 dex, g_obs as tabulated):
      NULL EXPECTATION of beta   = -0.0078    (the naive assumption is 0)
      null sd                    = 0.0192
      null 2.5-97.5 pct          = [-0.0468, +0.0289]
      OBSERVED beta = +0.1716  ->  z = +9.34 against its own null, p = 0
