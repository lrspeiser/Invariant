Why 21 families and not a billion formulas

Every family on the declared ladder is linear in its unknown coefficients, so no family is searched by trying formulas one at a time: a single exact linear solve either pins down the one member that fits the rows or proves that no member of that family can. That is why the funnel counts 21 declared families rather than individual formulas — each family is an infinite space of formulas, searched perfectly in one step. The ladder itself is a hand-declared, frozen list ordered by simplicity, which makes “simplest surviving family” a checkable claim relative to the declaration rather than a matter of taste. Anything outside the ladder is invisible to this search, and when the rows demand such a shape the system emits a typed blocker instead of an answer — the abstention worlds in this campaign are exactly that, receipted. import Std.Tactic

namespace SolvedDozenWorld02

def companion : Nat → Nat
  | 0 => 0
  | n + 1 => companion n + (6 * n ^ 2 + 12 * n + 6)

/-- Obligation 1 of 3: the base case, isolated from all algebra. -/
theorem companionBaseCase : companion 0 = 2 * 0 ^ 3 + 3 * 0 ^ 2 + 0 := by
  rfl

/-- Obligation 2 of 3: a pure polynomial identity. No induction appears here. -/
theorem companionSuccessorIdentity (n : Nat) :
    (2 * n ^ 3 + 3 * n ^ 2 + n) + (6 * n ^ 2 + 12 * n + 6) = (2 * (n + 1) ^ 3 + 3 * (n + 1) ^ 2 + (n + 1)) := by
  simp only [
    Nat.pow_succ,
    Nat.pow_zero,
    Nat.one_mul,
    Nat.mul_one,
    Nat.mul_assoc,
    Nat.add_mul,
    Nat.mul_add,
  ]
  omega

/-- Obligation 3 of 3: the induction skeleton. It cites the two lemmas above and
    performs no algebra of its own. -/
theorem companionClosedForm (n : Nat) :
    companion n = (2 * n ^ 3 + 3 * n ^ 2 + n) := by
  induction n with
  | zero => rfl
  | succ n ih =>
      rw [companion, ih]
      exact companionSuccessorIdentity n

end SolvedDozenWorld02
