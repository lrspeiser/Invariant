# Gravity research leads

This directory preserves the strongest results from the completed 72-item gravity
roadmap as separate research programs. The ranking is based on held-out evidence,
robustness to influential objects and uncertainty, relevance to the gravity question,
and distance from a genuine first-principles theory.

No folder represents a discovered replacement for general relativity, evidence that
dark matter is unnecessary, or a claim of historical novelty. A failed object is kept
as evidence and never acts as a terminal veto by itself. Broad unchanged failures,
hard analytic contradictions, and missing theory structure still prevent promotion.

## Shared admission rule

A descendant becomes a serious gravity candidate only if it:

1. is generated before target access and uses no object-type label;
2. follows from an action or a closed, causal field system;
3. has universal dimensionless parameters;
4. restores GR in the Solar System and other high-acceleration domains;
5. derives massive-particle motion and photon lensing from the same physical fields;
6. survives frozen galaxy, group, cluster, and direct-lensing tests;
7. separates measurement/calibration uncertainty from empirical mismatch;
8. receives unchanged external replication and specialist prior-art review.

The proposed first descendant of Rank 1 is documented in

Its first frozen exhaustive test is documented in
