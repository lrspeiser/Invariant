# Shared target-blind gravity evaluator V1

V1 proves that one predictor-only interface can be passed through four separate adapters without leaking responses into generation. It is infrastructure validation, not a scientific cross-scale result.

The generation packet contains exactly four typed dimensionless predictors: normalized source strength, normalized radial coordinate, continuous state, and geometry. It contains no object or survey labels, domain labels, outcomes, inferred total mass, fitted target coefficients, or data rows. The packet and a separate evaluation-only candidate registry are content-hashed before any injected response is created or any exposed target field is read.

The registry binds the existing `BEN-additive-cross-scale-v1` architecture as registered but unscored. Its status remains `PREFLIGHT_ONLY_CHILD_NOT_EXECUTED`. Twelve fixed injected controls—Newtonian, a known mapping, and a deliberately wrong mapping for each adapter—are plumbing controls, not candidate discoveries. Neither their forms nor B+E+N are selected or retuned on exposed responses.

## What runs

- Galaxy rotation: the adapter is exercised with injected label-free rows. The real-data smoke reads only the committed 139-object/2,720-row exposure receipt metadata. It opens no raw row because the consolidated raw file also contains later-designated confirmation rows.
- X-COP clusters: only the eight already-exposed development objects are parsed. Density predictors and pressure/temperature schemas are checked for finiteness and hashed. No formula is scored. The four formerly sealed but historically used Item 59 holdout objects are forbidden from reuse.
- Groups: the typed schema and injected recovery run. No eligible real group packet exists, so empirical rows and scores are fail-closed absent.
- Lensing: the typed metric-potential schema and injected recovery run. With no frozen photon law or direct-lensing authorization, empirical rows and scores are fail-closed absent.

Each adapter gets two 64-row injected packets: one generated by its Newtonian control and one by its known-law control. All three frozen controls are evaluated, the injected control must be recovered exactly, the wrong-law control must lose, and independent scalar/vector implementations must agree to `1e-12`. A pass establishes wiring and accounting only.

It reports raw/equivalence counts, exact target fields and rows read, every injected recovery result, per-domain counts, data seals, and compute/call accounting. `single_counterexample_is_universal_veto` is frozen to false.

## What remains blocked

Scientific use requires an exploration-only galaxy row packet, a real target-blind group packet, a covariant or otherwise frozen B+E+N child with no response tuning, and one action-derived photon law plus explicit lensing authorization. Independent validation and publication claims remain downstream of those gates.
