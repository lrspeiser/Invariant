Methods · archival astronomy

Nine Artefacts

A gravity-search programme produced nine confident, plausible, wrong results over eighteen months. None came from a coding error. Each was killed by a control that cost less than the analysis it invalidated. This is the catalogue.

Invariant gravity programme · lrspeiser/Invariant
Draft — 7 September 2026

Archival astronomy is now a pipeline of remote services, and its dominant failure mode is not arithmetic. It is a confident number of plausible size, produced because something upstream silently substituted a dataset, an instrument imprinted its own signature, two axes shared a construction term, or a null distribution was too small to show its own width.

We document nine such results from a single programme, each with the mechanism that produced it and the specific control that caught it. Seven concern analysis; five concern data acquisition. In every case the naive result would have passed peer review on its face. We give the detectors as a checklist and argue that the cost of running them is approximately zero relative to the cost of not.

§1

The failure that matters is not arithmetic

Every artefact below survived code review. The arithmetic was right. What was wrong sat one layer out: in what the archive actually returned, in what the instrument contributed, in what two variables silently shared, or in how the significance was sized.

These failures have a common shape. The pipeline runs to completion. No exception is raised. The output has the right units, a plausible magnitude, and often a striking significance. And because a striking result is the thing one was hoping for, it is the thing least likely to be interrogated.

A pipeline that cannot fail loudly will fail quietly, and quiet failure is indistinguishable from discovery.

The programme that produced these was searching for a modification to gravity across galaxies and clusters. It found none. What it did accumulate is a record of how a well-intentioned analysis manufactures signal, which we think is the more transferable result.

§2

Seven ways an analysis manufactures signal

Ordered as they occurred. The count matters: each was found only after the previous one had taught the programme to look, and the ninth was still missed on the first pass.

1

The label control

A variable search selected seven environmental variables as predictive of the gravitational residual. The identical search was then run on data containing only survey structure and no physics.

It selected the same variables, with a larger apparent gain. All seven were retired.

A correlation that ran backwards

A reported environmental correlation of ρ = −0.304 was retracted after re-derivation: the sign was a statistical artefact of the estimator, not a property of the sky.

Recorded here because retraction is the rarest of these outcomes, and the programme's own record carries the retraction alongside the claim.

The void-finder's own bias

A redshift path-length effect was measured at 30–38σ on data constructed to contain no path effect at all. The bias came from the void-finding algorithm, and differed between VoidFinder and REVOLVER.

A transverse decomposition orthogonal to distance reduced it 60× and 24× respectively — and still did not reach zero.

Both axes shared a term

A shape-factor correlation was traced to a quantity appearing in the construction expression of both axes. The correlation was a restatement of the shared term.

The check that caught it is mechanical and takes minutes: write out the construction expression for each axis and look for common factors.

Noise in a published X-ray density fit, propagated through the estimator with the true effect set to zero, did not average out. It drove the estimator to a significant negative value.

§3

The eighth: a radius divided by itself

A trend reported against normalised radius r/R500 turned out to be a trend against r. The normalising aperture was itself derived from the same profile, so the ratio carried no information the raw radius did not.

The trend survived. The phrase did not: nothing about the result was scale-free, and every sentence claiming it was had to be rewritten. This is the mildest artefact in the set and the most common in the literature.

§4

The ninth: the null was too small to see its own width

This one was found while preparing this paper, which is the reason it is here.

A machine-learning test asked whether the asymmetry of a cluster's gas predicts the asymmetry of its gravitational lensing — a question that required building a dataset where nothing was azimuthally averaged. The model's improvement was compared against a permutation null that shuffles direction while leaving every radial quantity intact.

With 40 permutations the result was a 2.7σ detection. With 200, on identical data, it was 1.6σ and not significant.

PermutationsNull meanNull width SignificancepVerdict written
40−0.01650.0095 +2.67σ0.000 “the cells DO see the asymmetry”
200−0.00910.0144 +1.64σ0.055 no detectable signal

Nothing about the data changed. The null distribution is simply wider than forty draws could resolve, and the undersized null manufactured a detection out of a fluctuation.

A permutation test with too few permutations is not a weak control. It is a signal generator.

Two controls run at the same time did behave correctly, which is what localises the failure to the null size rather than the pipeline: a brightness proxy substituted for the asymmetry feature carried nothing (+0.63σ), and swapping the target to the parity-odd shear component — which gravitational lensing cannot produce — was also null (−0.28σ).

Five ways an archive hands you the wrong data

The analysis failures above have a sibling family that is less discussed and easier to fix. Modern archives answer over HTTP, and HTTP has exactly one obvious success signal, which several services return while doing something other than what was asked.

§6

The checklist

None of these is novel in principle. Permutation tests, blind analysis and pre-registration are all standard. What the record above shows is that knowing about them is not the same as running them, and that the specific form each must take is not obvious in advance.

Run the search on data that cannot contain the answer

Structure-only, label-scrambled, or an empty patch of sky. If the method scores as well there, it has found the survey, not the universe. Case 1 was caught this way, and the null scored higher than the data.

Size the null before you trust it

Enough draws that the null's own width has converged. Forty is not enough, and the failure is not conservative — it inflates significance. Plot the null's standard deviation against draw count and stop when it is flat.

Choose the null that leaves everything else intact

To test whether direction matters, permute direction only, within object and radius. A null that also destroys the radial structure is answering an easier question and will be beaten by a model that knows nothing about direction.

Write out both construction expressions

Before quoting a correlation, write down how each axis was built and look for common factors. Cases 4 and 8 were shared terms; the check takes minutes and needs no compute.

Propagate the catalogue's errors through your estimator

Set the true effect to zero, redraw the inputs at their published uncertainties, and see where the estimator lands. Cases 5 and 6 both had a preferred sign under the null; neither averaged out.

Vary the sample size

A real signal is indifferent; a shot-noise signal scales. Case 7 fell from 12.4 to 1.10 between 102 and 105 objects.

Validate the fetch on three independent detectors

Transport, structure and identity. Status codes and filenames are not identity; a header written by the data provider is. Never let a single check stand alone.

Keep a parity-odd null in every lensing analysis

The cross component cannot be produced by gravitational lensing. Run it through the identical pipeline. If it shows your signal, the signal is your pipeline.

§7

What the programme found

No modification to gravity. Across galaxies, weak lensing, cluster outskirts and wide binaries, every candidate family was either eliminated or blocked before it could be scored.

Three exact results survive, all data-free: a stationary speed-only no-go, a cone-straddling and finite-mixing-range pair for kinetic gating, and a range–source tradeoff for split gates. Everything phenomenological failed.

The one place the data still disagrees with the simple picture is clusters, and the disagreement is organised by radius. We report it as a lead, not a result, and we note that the correlation supporting it rests on twelve objects — which, given the eight cases above, is not a number we are willing to build on.

Data and code. The full record, every lane's code and the machine-readable results are in the programme repository. Each artefact above corresponds to a dated run entry with its own report, self-tests and result JSON. The ninth is work/wellnet-2026-09/clusterjoint/.

On the count. Nine is not a boast. It is the number of times a control was run and returned a verdict the analysis did not want, in a programme that ran roughly five controls for every search. A programme with a lower ratio would not have a smaller number; it would have a smaller known number.
