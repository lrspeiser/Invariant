## Objective and completion condition

principles, that uses one global set of constants to predict galaxy-outskirts
stellar motion, galaxy-cluster matter and light observations, and precision Solar
System behavior. Parameters cannot be retuned by object or by regime. An asymptotic
Newtonian limit alone is not a precision Solar System pass.

[`invariant-gravity-discovery-charter.md`](../invariant-gravity-discovery-charter.md).
All twelve promotion conditions must be supported before a discovery claim. A
useful exclusion or equivalence map is progress, not completion of this active
discovery goal. No finite campaign can exhaust every possible physical law.

## Search coverage, rather than repeated coefficient fitting

Every hypothesis card should state source content, state variables, action or
equations, symmetries, dimensions, boundary and initial conditions, global
constants, matter coupling, photon coupling, known limits, distinctive prediction,
prior-art equivalences, and unresolved mathematical obligations. A candidate
without a solver stays unresolved; numerical failure is not physical falsification.

| Physical possibility | Present implementation | Next discriminating work |
|---|---|---|
| Local scalar response | Regularized QUMOND control | Finite-acceleration local-limit errors; disk and cluster transfer |
| Additional scalar fields and cross-gradients | TRIMOND subclass | Nonspherical sources, independent solvers, joint member/cluster response |
| Higher spatial derivatives or length scales | Generalized-QUMOND subclass | Boundary terms, resolution/regularizer convergence, stability |
| Vector/tensor response and preferred directions | Not implemented in the extension | Derive an action and source-aligned tensor response; rotate all scenes |
| Nonlocal paths and source connectivity | Historical work to reconcile | Conserved causal kernels and partition-invariant source construction |
| History-dependent inertia or fields | Oscillator and wave controls only | Derive a candidate law; constrain initial state; orbit-frequency transfer |
| Environment and external fields | Joint periodic scenes and scalar point-source external quadrupole | Multi-field external boundary solution; isolated same-source interventions |
| New sources: stress, radiation, vacuum state | Not implemented in the extension | Explicit universal coupling and independent source observables |
| Geometry and matter/light coupling | Assumed metric only | Covariant completion and derived motion of matter, photons, and clocks |
| Formation, cosmology and nonlinear evolution | Not implemented in the extension | Perturbation health before costly evolution; known-limit controls |

These categories organize an extensible search; neither this table nor the
15-card catalogue certifies exhaustive coverage of the charter's ontology.
